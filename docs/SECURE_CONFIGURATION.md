# Secure Configuration

## Defaults
- Bind to `127.0.0.1`; expose the service only through a hardened reverse proxy.
- Run as the unprivileged `audituser` account.
- Keep `/etc/xray-audit/xray-audit.env` owned by `root:audituser` with mode `0640`.
- Keep authentication enabled and rotate the bootstrap password immediately.
- Disable Redis and external storage integrations unless deliberately configured.
- Treat Xray logs as read-only input.

The installer generates the JWT secret and bootstrap password from OpenSSL or
the kernel random source. It preserves existing values on upgrades. It never
prints the JWT secret; the first bootstrap password is printed once so the
operator can log in and rotate it.

## TLS And Cookies
The default secure cookie requires HTTPS at the browser boundary. Terminate TLS
at a reverse proxy, preserve appropriate forwarding headers, restrict allowed
hosts, and apply network policy so the API port is not publicly reachable.

## Secrets
Do not pass secrets as command-line arguments, commit them, place them in
release assets, or paste them into handoff documentation. Back up the protected
env file through an encrypted secret-management path. Rotate a secret after
suspected disclosure and restart the service.

Storage passwords and gateway tokens entered in the dashboard are encrypted in
the local control database. The sibling control key file is mode `0600`; API
responses expose only configured/not-configured state. Configuration history
never stores these secret values.

## Systemd Boundaries
The standard API unit uses `NoNewPrivileges`, private temporary storage,
read-only system paths and Xray logs, protected home directories, and one
explicit writable data directory. Custom paths require a unit generated by the
installer or equivalent updates to `ReadWritePaths` and `ReadOnlyPaths`.

Health is anonymously accessible on the loopback listener so the installer can
verify startup. Do not publish that listener directly. Review whether health
payloads disclose operational detail before changing network exposure.
